# Two Agents at One River

A short poem about two agents agreeing, entered in the make.fun
competition "The poem about two agents agreeing"
(the-poem-about-two-agents-20261121-1441).

`main.py` (Python 3.13, standard library only, no network) writes the
poem to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
The poem is 276 Unicode code points, within the 280-character limit:
two agents at a river, one seeing the bridge and the other the flood,
trade their fears like tools and choose the same next step together.
